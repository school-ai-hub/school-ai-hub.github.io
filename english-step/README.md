# English Step — GitHub Pages版

Sites版 v100（ソース 69150645929305ca82c08c2aa79d6493a23fb235）から作成した、サーバー不要の個人練習版。

公開場所は `/english-step/`。このフォルダーを既存のGitHub Pagesリポジトリのルートに配置します。ビルド、Node.js、APIキー、環境変数は不要です。リポジトリ全体の公開設定と既存サイトは維持します。

## 機能
- 教科書別教材、文法、英単語、英会話、Reading・Project、Listening BINGO、English Arcade。
- 学習記録は端末内のブラウザーに保存。生徒IDでのログインや先生への送信はありません。
- 先生用ログイン、授業のオンライン同期、ALT共有、English Linkのオンライン対戦は対象外。画面にも明示します。
- 元のSites版とデータベースは変更しません。既存の生徒ID・授業・履歴・録音データは公開リポジトリに含めません。
- 音声合成・マイク録音・音声認識はブラウザーに依存します。音声認識が外部サービスへ送信される場合があります。

## 更新と確認
HTML・JavaScript・CSS・画像をこのフォルダー内で編集します。内部パスは `/english-step/` を前提としています。異なるフォルダー名で公開する場合はパスも変更してください。自動生成した文章だけでなく、表示と練習動作を確認してください。

ブラウザー内の記録はサイトの移設で自動移行されません。端末のストレージ削除で失われます。写真・氏名・成績などの個人情報をこのサイトやリポジトリに保存しないでください。

第三者ライブラリのライセンス表記は同梱ファイルを参照してください。教科書本文を転載したサイトではなく、共通の練習教材を単元に対応づけています。
