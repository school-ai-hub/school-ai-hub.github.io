# English Arcade — GitHub Pages版

公開先: https://school-ai-hub.github.io/english-arcade/

English Step内のEnglish Arcadeを独立した静的サイトとして移設しました。HTML・CSS・JavaScript・画像だけで動作し、ビルド、APIキー、PHP、外部データベースは不要です。

## 使い方
小学3年〜中学3年（第3〜第9学年）と難しさを選び、6種類のゲームや冒険に挑戦します。OneNoteの学習シートには、上の公開先URLを貼ってください。

## 記録と音声
記録は利用した端末のブラウザー内に保存されます。教師への自動送信・ログイン・端末間同期はありません。ブラウザーデータを消すと記録も失われます。移設前の別ドメインの記録は自動移行されません。音声合成・音声認識はブラウザーや端末に依存します。
